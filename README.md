> 一个简洁、轻量、美观的 Typecho 主题。

Lumino 是一款为个人博客设计的 Typecho 主题，注重简洁的界面设计、舒适的阅读体验以及良好的运行性能。

## ✨ 特性

* 🎨 简洁现代的页面设计
* 🚀 轻量快速，优化加载体验
* 📱 支持响应式布局，适配移动端
* 🔧 易于配置和二次开发
* 💻 良好的 Typecho 兼容性

## 📦 安装

1. 下载最新版本主题文件：

```
https://github.com/xiamng0/lumino/releases
```

2. 解压主题到 Typecho 目录：

```
usr/themes/
```

3. 登录 Typecho 后台：

```
控制台 → 外观 → 启用 Lumino
```
