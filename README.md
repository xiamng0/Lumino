# Lumino 轻语博客 26.0

森林笔记风格 Typecho 主题模板。首页默认使用 `assets/forest-station.jpg` 作为沉浸式顶部封面，搭配深绿纸感界面与粗圆展示字体。

## 安装

1. 将 `Lumino` 文件夹上传到 Typecho 的 `usr/themes/` 目录。
2. 在后台「控制台 -> 外观」中启用「Lumino 轻语博客」。
3. 点击「设置外观」调整网站名称、网站描述、ICP备案号、首页文案、作者资料、导航、独立页面、首页分类、侧栏、目录、阅读时长、阅读进度、签到、模糊强度、配色、社交链接和自定义代码。

导航链接使用每行一条的格式。`home` 会自动指向首页；`page:页面别名` 会使用 Typecho 为该独立页面生成的 permalink，因此会自动匹配当前伪静态设置：

```text
首页|home
归档|page:archives
关于|page:about
```

请先在 Typecho 后台「管理 -> 独立页面」创建对应别名的页面，例如 `archives` 和 `about`。创建 `archives` 时可选择主题提供的「按时间浏览文章」模板。不存在的页面不会显示为链接，避免产生 404；其它已发布独立页面可按设置自动加入导航栏。

主题不依赖第三方 CDN。主题内置 `logo.svg` 简约 Logo、`screenshot.png` 主题封面和 `assets/forest-station.jpg` 默认顶部封面。填写 `heroImage` 后会覆盖默认顶部封面；填写 Logo 地址后，页头会优先显示自定义图片。

分类设置支持网格卡片或横向列表。每行格式为 `分类别名|显示名称|分类简介|强调色`，分类别名需要与 Typecho 后台「管理 -> 分类」中的别名一致。封面文件为 `screenshot.png`。

## 主题控制台

「设置外观」会加载 Lumino 自定义控制台，将设置划分为网站、首页、导航、阅读、外观、高级和关于七个模块。它只重组 Typecho 原有的主题设置表单，保存仍由 Typecho 的安全接口完成。主题提供 48 项可配置内容，包括伪静态自适应页面导航、归档模板、淡薄荷配色、可视化颜色选择器、ICP备案号、阅读目录与进度、复制文章链接和浏览器本地签到。Logo、封面、头像和网站图标支持从本地上传；关于板块提供作者、项目、QQ群、作者QQ和邮箱信息。
